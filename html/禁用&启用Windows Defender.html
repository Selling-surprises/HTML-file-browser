禁用/启用Windows Defender

第一步，先打开Windows安全中心，选择“病毒和威胁防护”→“管理设置”

第二步，在"病毒和威胁防护"设置中，关闭“实时保护”、“ 云提供的保护”、“自动提交样本”和“篡改防护”，这样就算临时关闭了Windows Defender

第三步，新建一个文本文档取名为“Windows Defender管理工具”，后缀名改为.bat（.txt改成.bat），编码格式改成ANSI

代码如下：

Bash 
@echo off & pushd "%~dp0" & color f0

net session >nul 2>&1 
if %errorlevel% equ 0 goto :Menu 

where powershell >nul 2>&1 && ( 
    powershell -Command "Start-Process '%~sdpnx0' -Verb RunAs" >nul 2>&1 
) || ( 
    mshta vbscript:CreateObject("Shell.Application").ShellExecute("%~s0","","","runas",1)(window.close) >nul 2>&1 
) 
exit /b 

:Menu
cls
title Windows Defender管理工具
echo.
echo 请选择：
echo.
echo 1、禁用Windows Defender
echo.
echo 2、启用Windows Defender
echo.
echo 请按数字键选择
CHOICE /C 12 /N >NUL 
IF "%ERRORLEVEL%"=="1" goto Disable 
IF "%ERRORLEVEL%"=="2" goto Enable

:Disable
cls
title 禁用Windows Defender
net stop wscsvc
sc config wscsvc start= disabled
reg add "HKLM\SYSTEM\ControlSet001\Services\SecurityHealthService" /v "Start" /t REG_DWORD /d "3" /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\SecurityHealthService" /v "Start" /t REG_DWORD /d "4" /f>nul
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender Security Center\Notifications" /v "DisableNotifications" /t REG_DWORD /d "1" /f>nul
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "SecurityHealth" /f>nul
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender" /v "DisableAntiSpyware" /d 1 /t REG_DWORD /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\SecurityHealthServicer" /v "Start" /d 4 /t REG_DWORD /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisSvc" /v  "start" /t reg_dword /d "4" /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WinDefend" /v  "start" /t reg_dword /d "3" /f>nul
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer" /v "SmartScreenEnabled" /d off /t REG_SZ /f>nul

echo.
echo 禁用Windows Defender成功！请关机重启后试试
echo.
echo 按任意键返回菜单
pause>nul
goto Menu

:Enable
cls
title 启用Windows Defender
reg add "HKLM\SYSTEM\ControlSet001\Services\SecurityHealthService" /v "Start" /t REG_DWORD /d "2" /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\SecurityHealthService" /v "Start" /t REG_DWORD /d "2" /f>nul
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender" /v "DisableAntiSpyware" /d 0 /t REG_DWORD /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\SecurityHealthServicer" /v "Start" /d 2 /t REG_DWORD /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WdNisSvc" /v  "start" /t reg_dword /d "2" /f>nul
reg add "HKLM\SYSTEM\CurrentControlSet\Services\WinDefend" /v  "start" /t reg_dword /d "2" /f>nul
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer" /v "SmartScreenEnabled" /d on /t REG_SZ /f>nul
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "SecurityHealth" /t REG_EXPAND_SZ /d "%%windir%%\system32\SecurityHealthSystray.exe" /f>nul
sc config wscsvc start= auto

echo.
echo 启用Windows Defender成功！请关机重启后试试
echo.
echo 按任意键返回菜单
pause>nul
goto Menu

第四步，运行“Windows Defender管理工具.bat”，输入数字1，然后重启就行了

启用Windows Defender也是很简单的，直接运行批处理程序，输入数字2，然后重启

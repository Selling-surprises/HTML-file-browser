通过命令行打开UWP应用

近期由于需要在WinX菜单中添加⼏个UWP应⽤，但发现很难找到相应的命令⾏，Universal Apps 的快捷⽅式属性⾥也没有。

于是到⽹上搜了很久才找到⼀个E⽂的⻚⾯，试了⼀下确实可⾏，分享给⼤家：

1、打开PowerShell，并输⼊命令 get-appxpackage > 1.txt，然后输⼊命令notepad 1.txt，打开这个⽣成的1.txt⽂件

或者打开“获取已安装UWP应用信息.bat” 更改编码为ANSI

JavaScript 
@echo off&(pushd "%~DP0")&TITLE 获取已安装UWP应用信息&color f0&(REG QUERY "HKU\S-1-5-19">NUL 2>&1)||(powershell -Command "Start-Process '%~sdpnx0' -Verb RunAs"&&exit)
PowerShell get-appxpackage > %cd%\1.txt 
type %cd%\1.txt & del %cd%\1.txt 
pause


2、查找到PackageFamilyName值为快捷⽅式⽬标类型的那⼀个区块；

3、根据区块中的“InstallLocation”打开相应的⽬录；

4、打开⽬录中的“AppxManifest.xml”这个⽂件；

5、查找到“Executable=”这⼀⾏，可以在这⾏中得到应⽤的ID；

6、然后就可以在命令中输⼊以下命令来打开这个APP了。


命令行（注意PackageFamilyName和应⽤ID之间有个叹号） ：

Bash 
explorer shell:AppsFolder\应用的PackageFamilyName!应用的ID

举例

Microsoft Edge：

Bash 
explorer shell:AppsFolder\Microsoft.MicrosoftEdge_8wekyb3d8bbwe!MicrosoftEdge

Nativefier把网页转换成Windows客户端

1、安装node.js这个程序

可以到下面这个官网进行下载

https://nodejs.org/zh-cn/

2、安装完成后cmd里输入npm -v与node -v，这两条命令，检测node.js是否安装成功，如果出现版本号，说明安装成功

3、然后输入npm install nativefier -g，进行安装，如果不行，请用梯子（因为我这里是带梯子的，没有测试过不带梯子能不能下载安装）

4、再把cnpm安装，npm install -g cnpm --registry=https://registry.npm.taobao.org

5、通过cnpm安装electron，cnpm install -g electron

4与5这个两个命令据说有些电脑不需要，但是有些就需要，具体没有测试过，都是直接安装了这个两个命令。

可能你安装的时候，出现的不一定跟我的一样，但是只要安装成功了，就没问题了。

上面的都安装完成后，就可以把网页转exe的操作了，操作同样是在cmd里。

以吾爱网站为例，代码为：

nativefier --name "wuai" --tray "https://www.52pojie.cn/"或者nativefier "https://www.52pojie.cn/"

出现图片这样的字样后，代表操作完成了。

有些会整个文件夹出现在桌面，有些会在C:\Users\Administrator的文件夹里，一般文件名后面带-win32-x64的字样，如下图：

进入文件夹后，找到exe的程序，双击打开，就是吾爱网站的pc端了。
